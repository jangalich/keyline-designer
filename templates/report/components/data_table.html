DATA TABLE -- prose-face row labels down the left, data-face tabular figures right-aligned in every other column, hairline rules, a stock header row. `table` is {corner, columns: [str], rows: [{label, cells: [str]}], compact?, monthly?, variant?}. `variant` adds data-table-- so a section can set one of its tables' column widths without scoping the rule to the page block the table happens to sit on -- which a table that moves between pages (the Access and Soils spill rules) cannot rely on. A row label is a string (prose) or a list of summary-style parts, so a code inside it -- a slope class letter -- can be set as data. `compact` sizes the table to its content instead of the full measure -- for a table of three or four narrow columns; `monthly` is the twelve-column form (Climate's table, the seasonal water table), whose cells give up side padding to fit the measure. A CELL is a string, set in the data face, or a mapping {value, kind}: kind "bound" is a limit, not a measurement -- "> 72", the depth a water table is deeper than -- and is set muted so it cannot read as a depth; kind "word" is prose in a numeric column -- "no data" -- and takes the prose face; kind "text" is a PROSE COLUMN -- the Access section's limiting features -- set left, wrapping, in the page's ink, so the words that matter are not subordinate to the figures beside them. A CELL OF ANY KIND MAY CARRY A `note`: summary-style parts set on their own line INSIDE the cell, under the value. For a fact that qualifies one figure and nothing else -- a root restriction that is not the rock the depth column reports -- and that a caption below seven rows would be read after the conclusion it exists to prevent. It is not a footnote: there is no marker to follow, the words sit against the number they correct. Every value arrives ALREADY FORMATTED by the section builder (unit conversion and rounding are its job); this macro sets and aligns. -#} {% macro cell_note(parts) -%} {%- if parts %} {%- for part in parts -%} {%- if part is mapping -%}{{ part.value }}{%- else -%}{{ part }}{%- endif -%} {%- endfor -%} {% endif %} {%- endmacro %} {% macro data_table(table) -%} {%- for column in table.columns %} {%- endfor %} {%- for row in table.rows %} {%- for value in row.cells %} {%- if value is mapping and value.kind == "text" %} {%- elif value is mapping %} {%- else %} {%- endif %} {%- endfor %} {%- endfor %}
